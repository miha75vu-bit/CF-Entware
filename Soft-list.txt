# Soft list
# Одна программа — одна строка:
#   id | тип | папка | Название — пояснение
# тип:
#   ipk    — поставить все файлы .ipk из папки. Они же попадают в локальный фид soft.
#   script — запустить папка/install.sh
#   info   — только показать пояснение, ничего не ставить
# Папка «-» значит, что папки нет (для info).
# Свой .ipk: создайте папку, положите в неё файлы .ipk, добавьте строку с типом ipk.
# Удалить программу из меню: удалите строку и её папку.
# Не используйте id 0 и 99: 0 — выход в командную строку, 99 — удаление этой папки.
# Строки с # и пустые строки пропускаются.
