# CF-Entware
Entware с offline установкой пакетов для Keen/Net, с которой можно сразу пользоваться роутером: либо список нужных программ, либо Flashkeen при первом входе.

Чуть подробнее:
 
Обычная Entware после установки пустая. Дальше всё равно приходится отдельно ставить Flashkeen и каждую программу, если упали источники Entware резервных нет.

Здесь два готовых варианта:

1. Full С программами. При входе по SSH — список с пояснениями: Flashkeen, обход блокировок, VPN, торренты, фото и другое. Ставите только то, что нужно. Когда установщики больше не нужны, их можно убрать одним пунктом.
   
2. Base - Базовый. При первом входе сразу открывается Flashkeen: там же ставятся KeenSnap, KeenKit или оба. 

Список доступных программ в Full:
Flashkeen — помощник для дисков, бэкапов и Entware. При первой настройке ставит KeenSnap, KeenKit или оба сразу.
KeenSnap — бэкапы для обычной прошивки Keenetic и Netcraze.
KeenKit — бэкапы для прошивки Keenetic, поставленной на роутер другого производителя.
HydraRoute Neo — отправляет выбранные сайты и сети в VPN.
AWG Manager — страница в браузере для туннелей AmneziaWG.
NFQWS 2 Keenetic — обход блокировок без VPN. Не помогает, если сайт сам закрыл к вам доступ.
nfqws-menu — готовые стратегии для NFQWS 2 Keenetic.
z2k — тот же обход, но стратегия подбирается сама из короткого списка. В целом лучше не ставить: сделан небрежно, а чтобы убрать полностью, Entware проще поставить заново. Часто всё же работает.
web4static — страница настроек роутера в браузере, порт 99.
Smart-Photo — свои фото на флешке, с синхронизацией, без облака.
qBittorrent — торрент-клиент быстрее и удобнее встроенного в Keenetic.
Usque — доступ через сеть Cloudflare без отдельного VPN-сервера.
