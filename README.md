# CF-Entware
Entware с offline установкой пакетов для Keen/Net, с которой можно сразу пользоваться роутером: либо список нужных программ, либо Flashkeen при первом входе.

Чуть подробнее:
 
Обычная Entware после установки пустая. Дальше всё равно приходится отдельно ставить Flashkeen и каждую программу, если упали источники Entware резервных нет.

Здесь два готовых варианта:

1. Full С программами. При входе по SSH — список с пояснениями: Flashkeen, обход блокировок, VPN, торренты, фото и другое. Ставите только то, что нужно. Когда установщики больше не нужны, их можно убрать одним пунктом.
   
2. Base - Базовый. При первом входе сразу открывается Flashkeen: там же ставятся KeenSnap, KeenKit или оба.

## FAQ

<details>
<summary>Как добавить свою программу в Full?</summary>

Свои программы добавляются только в **Full**. В **Base** их нет.

1. Создайте папку `apps/<id>`. При сборке её содержимое попадёт в `/opt/Soft/<id>`.
2. Положите в неё:
   - `install.sh` для установщика-скрипта;
   - один или несколько `.ipk` для установки из пакетов. Чтобы установка была офлайн, положите рядом и все нужные IPK-зависимости.
3. Добавьте строку в `Soft-list.txt`, указав тот же `<id>` как папку:

   - `11 | script | my-tool | Моя программа` — запускает `apps/my-tool/install.sh`.
   - `12 | ipk | my-tool | Моя программа` — устанавливает IPK из `apps/my-tool/`.

ID должен быть уникальным; `0` и `99` зарезервированы. После публикации изменений GitHub Actions автоматически соберёт Full с программой.

Чтобы удалить программу, удалите её строку из `Soft-list.txt` и папку `apps/<id>`. Она исчезнет из следующей сборки Full.

</details>
## Автоматическая сборка

GitHub Actions ежедневно проверяет релизы Flashkeen, официальный установщик и базовые пакеты Entware, а также компоненты HydraRoute. Если эти источники обновились, CF-Entware автоматически собирается и публикуется заново; без изменений новый релиз не создаётся. 

<details>
<summary>Список программ в Full</summary>

Программы выбираются и устанавливаются отдельно из локального архива:

- **Flashkeen** — управление дисками, Entware и бэкапами.
- **KeenSnap** — резервное копирование для штатной прошивки Keenetic/Netcraze.
- **KeenKit** — резервное копирование для портированной прошивки Keenetic.
- **HydraRoute Neo (HR)** — направляет выбранные сайты и сети в VPN.
- **AWG Manager (AWGM)** — веб-интерфейс для AmneziaWG.
- **NFQWS 2 Keenetic** — обход блокировок без VPN.
- **nfqws-menu** — готовые стратегии для NFQWS 2.
- **Z2K** — автоматический подбор стратегии обхода; устанавливается онлайн.
- **web4static** — веб-настройка static-конфигов роутера.
- **Smart-Photo** — локальная фотогалерея с синхронизацией.
- **qBittorrent** — торрент-клиент.
- **Usque** — доступ через Cloudflare; устанавливается онлайн.

</details>
