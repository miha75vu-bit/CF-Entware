# CF-Entware
Entware с offline установкой пакетов для Keen/Net, с которой можно сразу пользоваться роутером: либо список нужных программ, либо Flashkeen при первом входе.

Чуть подробнее:
 
Обычная Entware после установки пустая. Дальше всё равно приходится отдельно ставить Flashkeen и каждую программу, если упали источники Entware резервных нет.

Здесь два готовых варианта:

1. Full С программами. При входе по SSH — список с пояснениями: Flashkeen, обход блокировок, VPN, торренты, фото и другое. Ставите только то, что нужно. Когда установщики больше не нужны, их можно убрать одним пунктом.
   
2. Base - Базовый. При первом входе сразу открывается Flashkeen: там же ставятся KeenSnap, KeenKit или оба.

## FAQ

<details>
<summary>Как добавить свою программу в Full? Пошаговый пример</summary>

Свои программы добавляются только в **Full**. В **Base** их нет. В исходниках не нужно создавать папку `Soft`: при сборке содержимое `apps/my-tool` само попадёт в `/opt/Soft/my-tool` внутри архива.

### Пример 1: программа устанавливается скриптом

1. Создайте папку `apps/my-tool/`.
2. Положите в неё файл `install.sh`. Он должен установить программу; если нужных пакетов нет в Entware, скрипт может скачать их при запуске.
3. Откройте `Soft-list.txt` и добавьте строку:

   ```text
   11 | script | my-tool | My Tool — краткое описание
   ```

4. Замените `11` на свободный номер меню. Номера `0` и `99` заняты. `my-tool` в третьей колонке должен в точности совпадать с именем папки.
5. Загрузите изменения в GitHub. После очередной автоматической сборки My Tool появится в меню **Full**.

При выборе пункта меню запускается `/opt/Soft/my-tool/install.sh`. Сборщик автоматически включает этот файл. Другие файлы из папки не копируются — установщик должен скачать их сам.

### Пример 2: программа устанавливается из IPK

1. Создайте папку `apps/my-tool/`.
2. Положите прямо в неё один или несколько файлов `.ipk`. Для полностью офлайн-установки добавьте туда и все нужные IPK-зависимости; во вложенные подпапки их класть не нужно.
3. Добавьте в `Soft-list.txt` строку:

   ```text
   12 | ipk | my-tool | My Tool — установка из IPK
   ```

4. `12` должен быть свободным номером, а `my-tool` — совпадать с именем папки. Загрузите изменения в GitHub: сборщик включит файлы в `/opt/Soft/my-tool/`, и пункт появится в меню **Full**.

При выборе пункта меню Entware установит все `.ipk` из папки и обновит индекс локального каталога.

### Удалить программу

Удалите её строку из `Soft-list.txt` и папку `apps/my-tool/`, затем загрузите изменения в GitHub. В следующей сборке пункт и его файлы исчезнут из **Full**.

## Автоматическая сборка

GitHub Actions ежедневно проверяет релизы Flashkeen, официальный установщик и базовые пакеты Entware, а также компоненты HydraRoute. Если эти источники обновились, CF-Entware автоматически собирается и публикуется заново; без изменений новый релиз не создаётся. 

<details>
<summary>Список программ в Full</summary>

Программы выбираются и устанавливаются отдельно из локального архива:

- **Flashkeen** — управление дисками, Entware и бэкапами.
- **KeenSnap** — резервное копирование для штатной прошивки Keenetic/Netcraze.
- **KeenKit** — резервное копирование для портированной прошивки Keenetic.
- **HydraRoute Neo (HR)** — направляет выбранные сайты и сети в VPN.
- **AWG Manager (AWGM)** — веб-интерфейс для AmneziaWG.
- **NFQWS 2 Keenetic** — обход блокировок без VPN.
- **nfqws-menu** — готовые стратегии для NFQWS 2.
- **Z2K** — автоматический подбор стратегии обхода; устанавливается онлайн.
- **web4static** — веб-настройка static-конфигов роутера.
- **Smart-Photo** — локальная фотогалерея с синхронизацией.
- **qBittorrent** — торрент-клиент.
- **Usque** — доступ через Cloudflare; устанавливается онлайн.

</details>
